# eosed-rs — port state

Rust port of https://github.com/lentferj/eosed (Python, GPL-2.0-or-later).
Source of truth read from: ~/.hermes/cache/scratch/eosed (clone).

## Ported and verified (39 unit tests green, `cargo test`)
- messages.rs  — full editor-protocol codec (40+ frames, 14-bit codecs, checksums)
- params.rs + params_data.rs — 267-param table (generated by
  ~/.hermes/cache/scratch/gen_params_rs.py — regenerate, don't hand-edit data),
  describe/cnv_* conversions
- lcd.rs, panel.rs — bitstream display decoder + panel protocol
- bridge.rs — dump OLD/NEW receive (retry/NAK/trim), OLD send handshake,
  parameter ops, signed_value, program change; engine behind MidiIo/Backend traits
- config.rs — vinsynlib Settings semantics pinned by the Python source:
  missing file = empty, unparseable = "unreadable" + refuse-to-overwrite,
  foreign-owned header reads empty, tables/lists refused, atomic temp+rename
  writes, cp1252 lenient decode, warn-once messages — plus the thin
  load_last_ports/save_last_ports/cache_depth/early_stop wrappers
- backend_midir.rs — REAL transport via midir 0.11 (CoreMIDI/ALSA/WinMM),
  callback-queue receive mirroring rtmidi's non-blocking get_message;
  client-per-open lifecycle matches the Python leak-fix concern
- standard_bridge / autodetect — port-sweep state machine with warm cached
  pair, broadcast inquiry, multi-device refusal (AmbiguousDevice twin)
- bin/eosed_cli.rs — CLI twin of eosed/cli.py: ports, hardware/inquire,
  config, memory, catalog, get, dump, send (--allow-write/--yes guard);
  exit codes 0/1/2

## Real-transport status on this host
- `cargo run --bin eosed_cli -- ports` enumerates 12 CoreMIDI ports
  (SSL V-MIDI stubs); `hardware` runs the autodetect sweep over all 12 and
  exits 1 with a clean "no EOS device answered" message (no hardware).
- Receive path is NOT yet exercised against a live device: no V-MIDI daemon
  and no EOS hardware here, so engine receive/ACK logic is proven only by
  the scripted-fake differential runs. A real E4/E4XT is the remaining step.
